# Super Intelligence Defence Lab website

Static site for the Super Intelligence Defence Lab (Station Zero), Xavier Institute of Engineering, Mumbai.

Pages: `index.html` (home), `services.html` (Lab Services), `ot.html` (OT Security).

## Before publishing
Fill the placeholders: `[EMAIL]`, `[CONTACT EMAIL]`, `[ENGAGEMENT NOTE]`, `[SEMESTER]`, `[YEAR / BRANCH]`, `[FACULTY NAME]`, `[YEAR]`.

## Hosting
Served as-is by GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
